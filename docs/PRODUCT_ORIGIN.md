# Product origin

NFRP originated from an earlier private product exploration called PROJECT-0-FP.

That exploration proposed:

```text
reusable operational core
+
industry-specific modules
=
customisable management platform for small businesses
```

Transport was selected as the first vertical because it provided direct access to real workflows and feedback. NFRP is the concrete reference implementation produced from that exploration.

The relationship is conceptual rather than a claim that a universal ERP already exists. A genuinely reusable core should be extracted only after comparing at least two working verticals. Until then, NFRP remains a focused transport-operations implementation with clearly documented reusable boundaries.
